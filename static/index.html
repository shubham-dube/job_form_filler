🚀 How to Install in 30 Seconds

  1. Open Google Chrome or any Chromium browser (Edge, Brave, Kiwi).
  2. Navigate to chrome://extensions in your address bar.
  3. Enable "Developer mode" using the toggle in the top-right corner.
  4. Click "Load unpacked".
  5. Select the extension folder inside this project directory:
    d:\Projects\Job_Form_Filler\extension
  6. Pin the FormFiller AI icon to your browser bar!
